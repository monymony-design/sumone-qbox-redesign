# 썸원 홈 화면 리뉴얼 — 디자인 브리프

> 상태: 초안 (2026-09-09) · 현행 화면 자료 수급 전

## 1. 범위

- **대상**: 썸원 앱 **홈 화면 1개**
- **비대상**: 온보딩, 오늘의 질문 상세, 마이페이지, 결제, SumDay 등 그 외 화면
- **전제**: 기능 추가·삭제가 아니라 **홈에 있는 요소의 재배치·재그룹핑**이 기본. 요소를 홈에서 빼야 한다는 결론이 나오면 "어디로 옮길지"까지 함께 제안한다.

## 2. 목표

**복잡해진 홈을 정리한다.** 그동안 홈에 누적된 **이벤트 아이콘·프로모션 구좌**가 큐박스 주변에 얽혀 있어, 정작 핵심인 큐박스가 묻힌다. 이를 재그룹핑해 정보 위계를 다시 세운다.

동시에 **큐박스 4유형(주관식·드로잉·OX·음성)을 모두 담아내는 UI**여야 한다. 정리와 확장을 함께 해내는 것이 과제다.

## 2-0. 이번 리뉴얼의 핵심 변화 — 큐박스 다형화

홈의 중심인 **큐박스**가 기존 "주관식 1종"에서 **4가지 답변 유형**으로 확장된다. 매일 다른 유형이 배달된다.

| 유형 | 답변 방식 | 홈 카드가 감당해야 할 것 |
|---|---|---|
| 주관식 | 텍스트 입력 (기본 100자 / 골드 500자) | 현행과 동일 |
| 드로잉 | 질문에 맞는 그림을 그려서 답변 | 캔버스 진입 · 완성 그림 썸네일 미리보기 |
| OX | 질문에 O / X 로 선택 | 홈에서 바로 답할 수 있는지 여부가 쟁점 · 둘의 일치/불일치 표현 |
| 음성 | 목소리를 녹음해 답변 | 녹음 진입 · 재생 UI · 길이 표시 |

**설계 난점**: 유형이 매일 바뀌면 홈의 인상이 매일 흔들린다. 그런데 이번 목표는 "정리"다.
→ **변하는 것(유형)과 고정되는 것(홈의 뼈대)을 명확히 분리**하는 것이 시안의 핵심 과제.

각 유형은 최소 3가지 상태를 가진다: **아직 아무도 답 안 함 / 나만 답함(상대 대기) / 둘 다 답해서 공개됨**.
→ 4유형 × 3상태 = **12가지 홈 큐박스 상태**를 시안에서 다뤄야 한다.

## 2-1. 산출물 형태

시안은 **웹뷰(HTML) 프로토타입**으로 만든다. 피그마 정적 시안이 아니라 브라우저에서 실제로 눌러볼 수 있는 형태.
- 모바일 뷰포트 프레임 안에서 홈 화면을 렌더하고, 스크롤·탭 등 실제 감각을 확인할 수 있게 한다
- 위계안 비교 시 여러 안을 나란히 놓고 볼 수 있어야 한다
- 기술 스택: **단일 HTML 파일** (HTML+CSS+최소 JS, 빌드·설치 없음). 필요 시 아티팩트로 퍼블리시해 링크 공유

## 3. 제품 컨텍스트 (공개 자료 기준 학습)

- **본질**: 매일 질문 1개 → 각자 답변 → **둘 다 답해야 공개**되는 커플 교환일기
- **정서 축**: 반려몽(에그몬) 육성 + 방 꾸미기. 캐릭터 IP가 브랜드 자산의 중심
- **홈에 얹혀 있는 것들**(공개 정보로 파악한 범위): 오늘의 질문 진입, 반려몽·방, 메모(쪽지), 디데이, 조약돌·젬, 감정 트래커, 각종 이벤트/배너
- **톤앤매너**: 따뜻하고 감성적. "사랑을 기록한다"
- **규모**: DAU 약 130만 / MAU 약 300만 / 8개 언어 → **다국어 텍스트 확장(일본어·번체·영어)을 레이아웃 제약으로 반드시 고려**

**필수**

**있으면 좋음**
5. 메모(쪽지)가 붙어 있는 홈
6. 신규 유저 / 커플 연결 직후의 빈 상태 홈
